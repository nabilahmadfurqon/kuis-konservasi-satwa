# Kuis Konservasi Satwa Nusantara

Aplikasi web kuis interaktif bertema satwa endemik Indonesia menggunakan HTML5 Semantik, Tailwind CSS, dan Vanilla JavaScript.

## Fitur Utama
- **Lembar Jawab Peserta (LJK):** Input Nama, NIM, dan Kelas beserta indikator pilihan opsi (A-D) yang ter-update secara langsung.
- **6 Soal Pilihan Ganda:** Dilengkapi foto satwa, informasi habitat, dan koordinat geografis.
- **Pembahasan Terkunci:** Kunci jawaban dan penjelasan soal hanya bisa dibuka setelah peserta mengumpulkan jawaban.
- **Koreksi & Penilaian Otomatis:** Menampilkan skor akhir, jumlah benar, durasi pengerjaan, serta penanda jawaban benar/salah pada tiap soal.
- **Riwayat Nilai:** Menyimpan riwayat pengerjaan peserta di browser menggunakan `localStorage`.

Buka file `index.html` langsung di browser, atau jalankan menggunakan ekstensi **Live Server** di VS Code.
